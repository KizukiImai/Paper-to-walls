## 通常のHTTP一貫テストについて

本環境のブラウザはHTTPナビゲーションが `ERR_BLOCKED_BY_ADMINISTRATOR` になりました。また、Blobからのmodule Workerロードが進行しないため、上記の隔離テストでは明示的にclassic Workerへ束ねています。**製品の通常HTTP配信＋ESモジュール＋module Worker＋ブラウザfetch経路を無変更で通したE2E成功とは扱いません。**

実機で通常経路を確認するためのスクリプトを同梱しています。

```powershell
python tests/browser_v11.py
```

Python PlaywrightとChromiumが必要です。これらは開発テスト用であり、アプリの利用には不要です。
